# WeatherXM Match-Cut Video Backup (`data/videos`)

This orphan branch stores and backs up all rendered video slideshows and web delivery assets generated by the WeatherXM Match-Cut Video Pipeline (429 curated station frames).

## 📦 Video Catalog by Version & Treatment

Each version folder contains full master 1080p cuts, optimized 720p/mobile web streams, sliced web playback chunks (`Part_1`, `Part_2`, `Part_3`), and lightweight WebP poster images.

### Version A: 3-Frame Rhythmic Match-Cut (5 fps pace @ 15 fps)
- Master 1080p: `output/Version_A/station_matchcut_master_1080p.mp4` & `.webm`
- Web 720p: `output/Version_A/station_matchcut_720p.mp4` & `.webm`
- Mobile: `output/Version_A/station_matchcut_mobile.mp4` & `.webm`
- Sliced Parts: `output/Version_A/Part_1/`, `output/Version_A/Part_2/`, `output/Version_A/Part_3/`
